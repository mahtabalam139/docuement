Q83. Explain all Joins
Inner Join
SQL
SELECT *

FROM A

INNER JOIN B

ON A.id=B.id;

Show more lines

Returns matching rows.

Left Join
SQL
SELECT *

FROM A

LEFT JOIN B

ON A.id=B.id;

Show more lines

Returns all rows of A.

Right Join
SQL
SELECT *

FROM A

RIGHT JOIN B

ON A.id=B.id;

Show more lines

Returns all rows of B.

Full Join
SQL
SELECT *

FROM A

FULL JOIN B

ON A.id=B.id;

Show more lines

Returns everything.
