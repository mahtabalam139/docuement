Question 11

INNER JOIN

Returns matching records.

SQL

FROM clients c

INNER JOIN trades t

ON c.id=t.client_id;

Show more lines
LEFT JOIN

Returns all records from left table.

SQL
SELECT *

FROM clients c

LEFT JOIN trades t

ON c.id=t.client_id;
